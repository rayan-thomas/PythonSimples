# PythonSimples 🐍

Um repositório dedicado aos meus estudos práticos e projetos iniciais em Python. Este projeto foi criado para aplicar conceitos fundamentais de programação e configurar um ambiente de desenvolvimento profissional.

## 🚀 O que este projeto contém?

- **Programação Orientada a Objetos (POO):** Criação e manipulação de classes em Python (ex: classe `Livro` com atributos como título, autor, género e métodos de exibição).
- **Testes Práticos:** Ficheiros `.py` e Jupyter Notebooks (`.ipynb`) para testar a execução de código em tempo real.
- **Gestão de Dependências:** Utilização de `requirements.txt` para manter o ambiente organizado com bibliotecas essenciais.

## 🛠️ Tecnologias e Ferramentas

- Python 3.x
- Visual Studio Code
- Git e GitHub
- Ambientes Virtuais (`venv`)
- Bibliotecas configuradas: `pandas`, `numpy`, `matplotlib`, `seaborn`, entre outras.

## ⚙️ Como executar este projeto localmente

Se quiser clonar e testar este projeto no seu computador, siga os passos abaixo no seu terminal:

1. Clone o repositório:
   git clone https://github.com/2605284-commits/PythonSimples.git

2. Abra a pasta do projeto:
   cd PythonSimples

3. Crie e ative o ambiente virtual:
   python -m venv .venv
   .\.venv\Scripts\activate

4. Instale as dependências:
   pip install -r requirements.txt

5. Execute os ficheiros:
   python project.py
